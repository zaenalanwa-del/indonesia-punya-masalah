# Next-stage product/UI blueprint

The prototype UI is being expanded into a public portal + intelligence dashboard. It keeps the existing geometry pipeline independent and labels demo intelligence values as demo data.

Navigation covers: Beranda, Peta Indonesia (Indonesia/Provinsi/Kabupaten/Kota/Kecamatan/Desa-Kelurahan/Dusun), Masalah, Data & Statistik, Suara Masyarakat, Monitoring, Intelligence, Solusi, Control Center, and Akun.
